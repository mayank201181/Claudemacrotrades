FEEDER RUN: transcripts (daily 04:20 SGT). It transcribes the new podcast episodes of the shows the Podcast Digest follows, independently of Podwise, and the new videos of the YouTube Digest's 400 channels (captions through Supadata), and uploads the day's files for the digests to read; since 15 Nov 2026 the Podcast and YouTube digests read them first, with Podwise as the backup. Set up 15 Nov 2026 by the thread "Build podcast and YouTube transcription service". Work silently and do exactly these steps.
1. Run in the shell, as one foreground command with a timeout of 600000 ms:
   cd /tmp && python3 -I /mnt/project-files/transcribe/transcribe.py run --upload --cap-minutes 7
2. If the output has a line "note: time cap reached", run the same command once more (it continues where it stopped; nothing is done twice).
3. Take the CREATE_FILE blocks of the last run that printed a line starting "UPLOADS:" (since 15 Nov 2026 there are several: the podcast bundle, the YouTube parts youtube_transcripts_latest_p01, p02, ... and the index transcripts_index_latest, which comes last). For each block, in order, call the Google Drive create_file tool with exactly the five arguments it prints: title, parentId, contentMimeType, disableConversionToGoogleType (true) and base64Content. Copy base64Content character for character. It is a file reference, not file content: do not read the file, do not use textContent, do not change anything. If a returned fileSize differs from that block's EXPECT line, call create_file once more with the same arguments. Upload the index last, after every other block, because the digests read it to find the rest.
4. If step 1 printed FAILED twice on consecutive days (check the last lines of /mnt/project-files/transcribe/status.csv), post ONE line to Mayank: "The transcripts did not build today: <the reason printed>". Otherwise say nothing.
5. End the turn with no_reply_needed. No checklist, no other message, no other command. Never trash Drive files, never edit a script, never fire or change a scheduled task.
