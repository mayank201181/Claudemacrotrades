For each candidate write THE TEST, numbers in: (a) proxy = one universe asset_id, direction; (b) stop = 3 x ATR(20) from the entry, where ATR(20) is 1.25 x the mean absolute daily close change over the last 20 closes (closes only), or a nearer named fundamental level if one exists; target at least two stop distances away; (c) p that the target prints before the stop within the horizon, p0 = 1/(1 + r/r), EV = p x r/r - (1 - p); card only if EV > 0; p above 75% must name its basis; (d) horizon 60 to 90 sessions with an expiry date; (e) a dated catalyst or mechanism inside the horizon (event_brief or the pack); (f) WHAT IS PRICED: the trend state, positioning build-up, odds, implied vol; a card with the trend says so, a card against the trend names what turns it; (g) SIGNPOSTS: two falsifiable fundamental, policy or flow triggers that would end the view. One direction per asset across this sleeve; a card opposite to an open daily-book card is allowed (different horizon) but prints "against daily Pnn". Prefer differentials (a long and a short that cancel the common factor) where the scorecard gives both sides; express each leg as its own card only if each passes the test alone.
