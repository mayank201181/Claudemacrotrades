# Claudemacrotrades

Start every session by reading `STATUS.md` (current state, open items, decisions), then `README.md`.
Before ending a session, update `STATUS.md` with what changed and what is still open.
Merge your own `STATUS.md` or docs-only pull request before the session ends; an open one is how this file went
stale in October 2026. Code that is deployed or running must be on `main` in the same session. A pull request that
would change something live and has not been deployed stays open, and is listed under Open items in `STATUS.md`.

- Branch from `main`.
- This repo is public: never commit trade, theme or digest data, or tokens.
